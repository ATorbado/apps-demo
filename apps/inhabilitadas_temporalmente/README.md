# Inhabilitadas temporalmente

Estas aplicaciones se conservan como código de referencia. No se presentan como demos funcionales de su función principal:

- **HEALEXY:** requiere un esquema MySQL que no está en el repositorio. Además, el código PHP heredado necesita revisión de seguridad antes de publicarse como servicio.
- **WidgetTime:** compila, pero las consultas meteorológicas requieren claves nuevas de WeatherAPI y Visual Crossing. Sin ellas, la función principal no muestra datos actuales.

Moverlas aquí no las publica ni las ejecuta. Se devolverán a la lista de demos disponibles solo después de preparar una alternativa de demostración y verificar su recorrido principal.
